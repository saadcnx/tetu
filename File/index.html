05 QUESTIONS & ANSWERS

Good to
know.

The basics of how ZeroCommit fits into your coding workflow.

What exactly does ZeroCommit do?

ZeroCommit helps turn AI-generated code instructions into changes in your project. Paste the AI response, select your project and use Detect & Stage to process supported edits across matching files.

Do I need to use a specific AI model?

The workflow is designed to work with the AI you already use. Ask it to produce supported code-edit instructions, then pass the response to ZeroCommit. Supported formats depend on the product's implementation.

What is the difference between codebase export and Deep Map?

Codebase export combines project files into a readable text document. Deep Map provides a structured overview that can help an AI identify relevant files when the full codebase is too large to provide at once.

Can it handle projects with many files?

ZeroCommit is designed for multi-file editing workflows. The actual results depend on the instructions, matching code and supported project workflow. Deep Map helps you provide useful context for larger codebases.

Why not use an autonomous coding agent?

Autonomous agents can be useful for many tasks. ZeroCommit offers an alternative for developers who prefer to ask their AI for a solution and then apply the resulting supported instructions through a separate workflow.

Should I review changes before committing?

Yes. Always review important edits and run your project's tests before committing or deploying. A successful code match does not guarantee that the resulting application will behave correctly.
